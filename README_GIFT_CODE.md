# HICHAM Gift Code Demo

An independent static demo website stored in `docs/`.

## Publish with GitHub Pages
1. Open repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch `main` and folder `/docs`, then Save.
5. The site will be available at: https://hicham07dzz-cyber.github.io/ElevenLabs-Telegram-Bot/

## Important
This is a local demonstration only. `HICHAM100` is a sample code accepted by this page. It is not a Garena / Free Fire redeem code and does not grant in-game rewards. The site does not connect to Garena or collect account credentials.
