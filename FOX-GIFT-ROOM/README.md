# FOX GIFT ROOM — نظام هدايا مستقل

نسخة مستقلة مستوحاة من تجربة نظام الهدايا الذي أذن صاحبه بالاستفادة من أفكاره العامة. الواجهة عربية داكنة بلمسات برتقالية/ذهبية، مع مولّد هدايا ولوحة إدارة.

## ما الذي يعمل؟
- ربط كل مطالبة بـ UID محدد.
- إنشاء أكواد من لوحة الإدارة مع قيمة رصيد، حد استعمال، وتاريخ انتهاء.
- مطالبة اللاعب بالكود مرة واحدة لكل UID.
- إضافة رصيد افتراضي إلى محفظة هذا النظام وتسجيل العملية.
- إدارة الأكواد (عرض، إيقاف/تفعيل، حذف).
- تخزين مركزي في SQLite بدلاً من LocalStorage.

## التشغيل على Termux
يتطلب Python 3 فقط:
```sh
cd FOX-GIFT-ROOM
export FOXGIFT_ADMIN_KEY='ضع-مفتاحاً-سرياً-طويلاً-خاصاً-بك'
python server.py
```
افتح في المتصفح: `http://127.0.0.1:8765/`

لوحة الإدارة: `http://127.0.0.1:8765/admin.html`

أدخل مفتاح الإدارة في خانة لوحة الإدارة. لا تضع المفتاح في ملفات HTML أو في GitHub.

## ملاحظات مهمة
- هذه محفظة مستقلة تجريبية للروم، وليست رصيد Free Fire الرسمي.
- لا يوجد تكامل مباشر مع Craftland حتى الآن؛ يلزم دعم رسمي من Craftland وصلاحية تعديل الخريطة.
- GitHub Pages لا يشغّل Python؛ يجب تشغيل الخادم على جهاز/استضافة تدعم Python ليكون النظام متاحاً للاعبين عبر الإنترنت.
- لا ترفع قاعدة البيانات أو مفتاح الإدارة إلى المستودع.
- لا تستعمل أكواداً أو رموزاً صالحة لخدمة شخص آخر. الأكواد التي ينشئها هذا النظام مستقلة وخاصة بك.
