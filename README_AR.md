# بوت تيليجرام لتحويل النص العربي إلى صوت — ElevenLabs

يردّ البوت على النص الذي ترسله له بملف MP3 مولّد من حساب ElevenLabs.

## ما الذي يفعله؟
- تحويل النص العربي إلى MP3.
- `/voices` لعرض الأصوات المتاحة في حساب ElevenLabs.
- `/setvoice VOICE_ID` لاختيار صوت.
- `/voice` لعرض الصوت المختار.
- خيار `OWNER_ID` لقصر الاستخدام على حساب تيليجرام واحد.

## 1) إعداد الأسرار
أنشئ ملفاً اسمه `.env` بنسخ `.env.example`، ثم املأ:
- `TELEGRAM_BOT_TOKEN`: توكن البوت من BotFather.
- `ELEVENLABS_API_KEY`: مفتاح ElevenLabs.
- `ELEVENLABS_VOICE_ID`: يمكن تركه فارغاً أولاً ثم استخدام `/voices`.

**ممنوع رفع `.env` إلى GitHub.** ملف `.gitignore` يمنع ذلك عادةً، لكن تأكد من عدم ظهوره ضمن الملفات المرفوعة.

## 2) تشغيله على Android عبر Termux
ثبّت Termux من مصدره الرسمي، ثم نفّذ:

```bash
pkg update -y
pkg install python git -y
```

انتقل إلى مجلد المشروع ثم:

```bash
pip install -r requirements.txt
cp .env.example .env
nano .env
python bot.py
```

احفظ الملف في nano عبر `CTRL+O` ثم Enter ثم `CTRL+X`.

## 3) أول استخدام
1. افتح البوت في Telegram واضغط Start.
2. أرسل `/voices` لعرض الأصوات الموجودة في حسابك.
3. اختر معرّف الصوت وأرسل `/setvoice VOICE_ID`.
4. أرسل جملة عربية. سيعود إليك ملف MP3.

## 4) رفع المشروع إلى GitHub من الهاتف
ارفع ملفات المشروع فقط: `bot.py`, `requirements.txt`, `.env.example`, `.gitignore`, `README_AR.md`, `run.sh`.
لا ترفع `.env` أبداً، ولا تضع أي مفتاح أو توكن داخل الكود.

## ملاحظات
- استخدام API يخضع لخطة ElevenLabs ورصيد الحساب وحدوده؛ لا يوجد ضمان أن الاستخدام مجاني أو غير محدود.
- تشغيل البوت داخل الهاتف يتطلب بقاء Termux عاملاً، وقد يوقف Android التطبيق بسبب توفير البطارية.
- جودة العربية واللهجة تعتمد على الصوت الذي تختاره.
- إذا سبق أن شاركت مفتاحاً أو توكناً في محادثة، ألغِه وأنشئ بديلاً قبل التشغيل.
