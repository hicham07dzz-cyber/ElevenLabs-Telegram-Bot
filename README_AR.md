# VoicePro Bot — بوت تحويل النص العربي إلى صوت

بوت تيليجرام بواجهة عربية تعتمد على الأزرار لتحويل النص إلى MP3 باستخدام ElevenLabs.

## المميزات
- قائمة رئيسية بأزرار واضحة.
- عرض الأصوات على صفحات واختيارها بالضغط على الاسم.
- حفظ اختيار الصوت لكل مستخدم محلياً في SQLite.
- تجربة صوت مختار بعينة قصيرة (قد تستهلك رصيد API).
- رسائل عربية مبسطة للأخطاء، وإخفاء تفاصيل API الحساسة.
- ضبط اسم البوت ووصفه المختصر والوصف الطويل تلقائياً عند التشغيل.
- إخفاء الأصوات المصنفة ضمن Library لتقليل أخطاء الخطة المجانية.

## الإعداد
1. انسخ `.env.example` إلى `.env`.
2. ضع توكن تيليجرام ومفتاح ElevenLabs في `.env` فقط.
3. ثبّت المتطلبات: `pip install -r requirements.txt`.
4. شغّل: `python bot.py`.

لا ترفع ملف `.env` إلى GitHub ولا ترسله لأي شخص.

## الاستخدام
اضغط Start، ثم اختر الصوت من زر «اختيار الصوت». بعد ذلك أرسل النص مباشرة، أو استخدم زر «تحويل النص إلى صوت». يمكنك تجربة الصوت من زر «تجربة الصوت».

## معلومات مهمة
- ظهور الصوت في قائمة API لا يعني أن خطتك تسمح بتوليد الصوت به. قيود ElevenLabs ورصيد الحساب تظل سارية.
- إخفاء فئة Library مبني على حقل التصنيف الذي يعيده API؛ وقد تظل بعض الأصوات غير مؤهلة، لذلك يعرض البوت رسالة مفهومة عند رفض الطلب.
- عينة التجربة تنفّذ طلب توليد حقيقياً وقد تستهلك رصيداً.
- اختيار الصوت يُحفظ في قاعدة بيانات SQLite محلية. في الاستضافات ذات التخزين المؤقت قد تحتاج إلى قرص دائم حتى لا تفقد الإعدادات بعد إعادة التشغيل.
- اسم البوت ووصفه يُضبطان من Bot API عند التشغيل. صورة الحساب لا يمكن تغييرها من هذا الكود؛ غيّرها يدوياً من BotFather.
- التشغيل داخل Termux يتطلب بقاء الهاتف والتطبيق والإنترنت متاحين.
