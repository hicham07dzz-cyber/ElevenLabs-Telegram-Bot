# AUTOFOX EDIT — نسخة تجريبية للأندرويد

واجهة عربية محلية قابلة للتثبيت من المتصفح، مع محرك مونتاج أولي يعمل على الهاتف عبر Termux.

## التثبيت على Android / Termux

افتح Termux ونفّذ:

```bash
pkg update
pkg install python ffmpeg
termux-setup-storage
```

حمّل ملفات مجلد `AUTOFOX_EDIT` من فرع `autofox-edit` إلى مجلد واحد على الهاتف، ثم ادخل إليه وثبّت المتطلبات:

```bash
pip install -r requirements.txt
```

## تشغيل التطبيق

من داخل مجلد `AUTOFOX_EDIT`:

```bash
python app_server.py
```

افتح متصفح الهاتف على:

`http://127.0.0.1:8765`

اختر فيديو واضغط «ابدأ المونتاج التلقائي». يمكن تثبيت الواجهة من قائمة المتصفح عبر «إضافة إلى الشاشة الرئيسية» عندما يكون ذلك متاحاً.

## ما الذي يعمل في هذه النسخة؟

- واجهة عربية لاختيار الفيديو.
- رفع الفيديو إلى خادم محلي على نفس الهاتف.
- اكتشاف تغيّر المشاهد.
- تقدير الحركة واختيار مقاطع قصيرة.
- تركيب المقاطع في MP4 مع الاحتفاظ بالملف الأصلي.
- تنزيل الفيديو النهائي وتقرير JSON.

## ما الذي لم يكتمل بعد؟

هذه ليست بديلاً كاملاً عن CapCut حتى الآن. لا يوجد بعد فهم دلالي للمحتوى، أو كشف Headshot/Kill، أو توليد تلقائي للنصوص، أو موسيقى ومؤثرات وانتقالات احترافية، أو محرر زمني متعدد المسارات. يعتمد اختيار اللقطات حالياً على تغيّر المشهد وتقدير الحركة فقط. الأداء يتوقف على قوة الهاتف وحجم الفيديو.

## الخصوصية والمفاتيح

المعالجة الحالية محلية ولا تحتاج API أو مفتاحاً سرياً. لا ترفع مفاتيح API إلى GitHub ولا تضعها في ملفات المشروع. إذا أضيف مزود ذكاء اصطناعي لاحقاً فسيكون اختيارياً، مع حفظ المفتاح محلياً خارج المستودع.
