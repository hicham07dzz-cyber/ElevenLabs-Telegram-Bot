# AUTOFOX EDIT — نسخة تجريبية محسّنة للأندرويد

واجهة عربية محلية ومحرك مونتاج تلقائي يعمل على Android عبر Termux.

## التثبيت
```bash
pkg update
pkg install python ffmpeg
termux-setup-storage
```
لا يحتاج هذا الإصدار إلى pip packages أو OpenCV أو NumPy.

## التشغيل
```bash
cd ~/AUTOFOX_DOWNLOAD/AUTOFOX_EDIT
python app_server.py
```
افتح `http://127.0.0.1:8765` في متصفح الهاتف.

## المزايا الحالية
- رفع فيديو محلياً.
- كشف تغيّر المشاهد باستخدام FFmpeg.
- تقدير الحركة من فروق الإطارات.
- تقدير مستوى الصوت وترجيح المقاطع النشطة.
- اختيار أفضل المقاطع وترتيبها زمنياً.
- إخراج أفقي 16:9 أو عمودي 9:16 أو مربع 1:1.
- إضافة ملف موسيقى اختياري (يستبدل صوت الفيديو الأصلي).
- تنزيل MP4 وتقرير تحليل JSON.

## الحدود المعروفة
هذا ليس بعد محرراً بمستوى CapCut. لا يوجد فهم دلالي حقيقي للصورة، ولا كشف مضمون لـ Headshot/Kill، ولا توليد كلام/ترجمة/نصوص، ولا انتقالات سينمائية متقدمة أو مسارات تحرير متعددة. اختيار اللقطات مبني على مؤشرات الحركة والصوت وتغيّر المشاهد، وقد يختار لحظات نشاط لا تمثل حدثاً مهماً.

## الخصوصية
المعالجة محلية على الهاتف ولا تحتاج API أو مفتاحاً سرياً. لا ترفع مفاتيح خاصة إلى GitHub.
