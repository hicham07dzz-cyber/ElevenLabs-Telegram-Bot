# SmartCut AI — Android

تطبيق Android أصلي. البناء يتم عبر GitHub Actions على الفرع `smartcut-apk`.

## الإصدار 0.3.0 — الميزات المضافة في هذه الدفعة
- اختيار فيديو من الهاتف ومعاينته.
- تحليل أولي لإطارات الفيديو: الدقة والمدة ومتوسط السطوع وتغيّره.
- تفريغ صوت الفيديو عبر Whisper Large V3 Turbo من خلال Groq API مع توقيت المقاطع.
- موافقة صريحة قبل رفع الفيديو إلى خدمة خارجية. مفتاح API يُكتب داخل التطبيق ولا يُحفظ في ملفات المشروع.
- تحليل فترات الكلام من توقيتات Whisper، وتجميع المقاطع المتقاربة، واقتراح حذف فترات الصمت الطويلة.
- تصدير المقاطع المختارة بالتتابع، مع ترجمة متزامنة محروقة داخل الصورة عند توفر تفريغ Whisper.
- ترجمة المقاطع إلى العربية أو الإنجليزية مع الاحتفاظ بالتوقيت الأصلي، ثم حرقها داخل الفيديو وتصدير SRT متزامن.
- دمج موسيقى خلفية مع خفض مستواها آلياً أثناء فترات الكلام اعتماداً على توقيتات Whisper.
- تحسين بصري خفيف للسطوع والتباين.
- محادثة متعددة الرسائل مع محرر AI عبر Groq، يرد بالعربية ويقترح ثلاث نسخ تحرير نصية: سريعة ومتوازنة وسينمائية.
- مقاسات عمودي 9:16 وأفقي 16:9 ومربع 1:1.

## متطلبات خدمات AI
- يلزم اتصال بالإنترنت ومفتاح Groq API صالح، يُدخل داخل التطبيق فقط.
- لا تضع المفتاح في GitHub ولا ترسله في المحادثات.
- تُرفع نسخة الفيديو إلى Groq عند طلب التفريغ؛ لا تضغط الزر إلا إذا كنت موافقاً على مشاركة الملف مع الخدمة.
- الرفع المباشر محدد حالياً بحد 25MB في التطبيق؛ الفيديو الأكبر يحتاج تقليل حجمه أولاً.
- توفر الخدمة وحدودها قد تتغير حسب حساب المزود. هذا ليس وعداً بأن الاستخدام مجاني أو غير محدود.

## حدود الإصدار الحالي — ما لا ندّعي اكتماله
- اكتشاف الصمت مبني حالياً على الفجوات بين مقاطع الكلام التي يرجعها Whisper، وليس تحليلاً صوتياً waveform كاملاً.
- اقتراحات النسخ الثلاث نصية من محرر AI؛ لا تُنشأ بعد ثلاثة ملفات MP4 مستقلة تلقائياً.
- لا توجد حتى الآن انتقالات سينمائية متحركة بين المقاطع أو مؤثرات حركة متقدمة.
- خفض الموسيقى يعتمد على أوقات الكلام المكتشفة، وليس على فصل صوت المتحدث عن الموسيقى.
- يلزم اختبار APK على هاتف Android فعلي، وتجربة عدة صيغ فيديو وصوت قبل إعلان الجاهزية.

## بناء APK
افتح GitHub Actions ثم سير عمل **Build SmartCut AI APK** على الفرع `smartcut-apk`. بعد نجاح البناء نزّل artifact باسم `SmartCut-AI-debug-apk` وفك ضغطه للحصول على `app-debug.apk`.

الحزمة: `com.smartcut.ai`
