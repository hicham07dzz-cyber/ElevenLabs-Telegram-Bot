# SmartCut AI — Android

تطبيق Android أصلي، وبناء APK يتم عبر GitHub Actions.

## الموجود في الإصدار 0.1.0
- اختيار فيديو من الهاتف.
- معاينة الفيديو.
- تحديد بداية ونهاية المقطع بالثواني.
- قص وتصدير MP4 إلى Movies/SmartCutAI.

## ما لم ينفذ بعد
Whisper، تحليل المحتوى بالذكاء الاصطناعي، اكتشاف اللحظات المهمة، الترجمة التلقائية، الموسيقى الذكية، والجدول الزمني. لا نعتبر APK مختبراً حتى ينجح البناء وتجربة فعلية على هاتف Android.

## تنزيل APK
افتح Actions ثم Build SmartCut AI APK، شغّل Run workflow، وبعد نجاحه نزّل artifact باسم SmartCut-AI-debug-apk وفك ضغطه لتجد app-debug.apk.

الحزمة: com.smartcut.ai
